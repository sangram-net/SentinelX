# SentinelX

### Local Smart Log Sentinel

> **Turn logs into insights. Detect threats. Stay ahead.**

SentinelX is a lightweight local security log analysis and threat detection dashboard designed to transform raw system and web logs into understandable security incidents.

Instead of manually searching through hundreds of log lines, SentinelX parses events, identifies suspicious patterns, correlates related activity, explains why an event was detected, and presents the result through a security-focused dashboard.

---

## 🛡️ What Problem Does SentinelX Solve?

Security logs contain valuable evidence, but raw logs are difficult to understand quickly.

For students, developers, small teams, and local lab environments, setting up a complete enterprise SIEM can be unnecessary or too complex.

SentinelX provides a lightweight alternative for local environments:

```text
Raw Logs
   ↓
Log Ingestion
   ↓
Parser & Normalizer
   ↓
Detection Engine
   ↓
Incident Correlation
   ↓
Severity & Evidence
   ↓
Attack Story
   ↓
Security Dashboard
